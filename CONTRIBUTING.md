# Contributing to PreetiConverter

Thank you for your interest in contributing! 🙏

## How to Contribute

### Report a Bug
1. Go to [Issues](../../issues)
2. Click **New Issue**
3. Choose **Bug Report**
4. Describe the problem clearly

### Suggest a Feature
1. Go to [Issues](../../issues)
2. Click **New Issue**
3. Choose **Feature Request**
4. Explain what you want and why

### Submit Code (Pull Request)

```bash
# 1. Fork the repo on GitHub
# 2. Clone your fork
git clone https://github.com/YOUR_USERNAME/PreetiConverter.git
cd preeti-converter

# 3. Create a new branch
git checkout -b feature/your-feature-name

# 4. Make your changes
# 5. Commit with a clear message
git commit -m "feat: add support for XYZ character"

# 6. Push to your fork
git push origin feature/your-feature-name

# 7. Open a Pull Request on GitHub
```

## Commit Message Format

```
feat:     new feature
fix:      bug fix
docs:     documentation only
style:    formatting, no logic change
refactor: code restructure
test:     adding tests
```

## Areas You Can Help With

- 🔤 Improving Unicode ↔ Preeti character mapping accuracy
- 🌐 Adding more Nepali conjunct characters
- 🧪 Writing tests
- 📖 Improving documentation
- 🐛 Fixing bugs
- 🌍 Translation / localization

## Code Style

- Use clear variable names
- Add comments for complex logic
- Keep functions small and focused

## Questions?

Open an issue and ask — no question is too small! 🙏
